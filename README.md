# Lost & Found Management System

A web-based Lost and Found Management System developed as a final-year IT project at Richfield Institute of Technology.

## Features

- User Registration and Login
- Lost Item Reporting
- Found Item Reporting
- Item Claim Requests
- Admin Dashboard
- User Management
- Audit Logs
- AI Chatbot Assistant
- Image-Based Colour Detection

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Installation

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into the `htdocs` directory.
4. Open phpMyAdmin.
5. Create a database named `lostfound`.
6. Import the `lfs_db.sql` file.
7. Update database settings in `includes/config.php` if necessary.
